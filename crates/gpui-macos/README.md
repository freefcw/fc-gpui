# FC GPUI macOS

Internal macOS platform and Metal renderer crate for [fc-gpui](https://crates.io/crates/fc-gpui).

This package owns AppKit integration, Metal rendering, display and input handling, tray and global hotkeys, permissions, notifications, biometric APIs, auto-launch, power and network integration, and screen capture. Applications should normally depend on `fc-gpui` rather than this crate directly.
