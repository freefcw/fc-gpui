# FC GPUI Windows

Internal Windows platform and DirectX renderer crate for [fc-gpui](https://crates.io/crates/fc-gpui).

This package owns Win32 integration, DirectX rendering, display and input handling, tray and global hotkeys, overlay behavior, notifications, auto-launch, jump lists, power and network integration, screen capture, HLSL compilation, and manifest resources. Applications should normally depend on `fc-gpui` rather than this crate directly.
